Detailed Description

Main graphical user interface for rendering the game using Qt.

The GUI class inherits from QWidget and is responsible for rendering game entities (avatar, enemies, projectiles, power-ups) and handling user input (keyboard and mouse). It continuously updates the game view using a timer.
